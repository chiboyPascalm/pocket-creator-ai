# Pocket Creator AI

Pocket Creator AI is an offline-first content drafting studio for creators.

## Features
- Video scripts, stories, social posts, product promotions and captions
- Multiple writing tones
- Topic-aware draft templates and relevant hashtags
- Copy and regenerate controls
- Anna Executa tool interface
- Built-in drafting without a live AI model or API key

## Validate
```bash
anna-app validate
anna-app validate --strict
```

## Local development
```bash
anna-app dev
```

Content is template-generated. Personalize each draft and verify factual or promotional claims before publishing.
