PROJECT DESCRIPTION:
Pocket Creator AI is an offline-first content drafting studio
designed for digital creators.

The software provides tools for drafting video scripts, stories,
social media posts, product promotions, captions and structured
ebooks. Features include writing tones, content templates,
topic-aware hashtags, draft management, PDF downloads and
branded PDF exports.

The project includes a user interface and a bundled Creator AI
software tool.
